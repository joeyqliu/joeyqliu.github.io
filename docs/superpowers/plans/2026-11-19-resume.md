# Resume Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move experience into one data file that drives both `/work` and a new printable `/resume` page.

**Architecture:** `src/data/experience.ts` exports typed `jobs` + `education` plus two filter helpers. `/work` maps `workJobs()`; `/resume` maps `resumeJobs()` with print CSS for a one-page Letter export.

**Tech Stack:** Next.js 16 static export, Tailwind 3, `next/font/google`, `node --test` (Node 22 type stripping).

**Spec:** `docs/superpowers/specs/2026-11-19-resume-design.md`

## Global Constraints
- No phone number and no city anywhere on `/resume`.
- Fonts: Bebas Neue (headings) + Poppins (body), via `next/font/google`. No new npm deps.
- `onWork` defaults to true when omitted; `onResume` defaults to false when omitted.
- `/work` visible output unchanged (same text, order, open state).
- Data file must use relative imports only (`node --test` can't resolve `@/`).

## Review Focus
- Job with `onWork` omitted → still shows on `/work` (test in Task 1).
- Job with `onResume: true` but empty `resume` list → renders header with no bullets, no crash (test in Task 1 asserts helper returns it; page maps empty array).
- Print in dark mode → must still print black on white (Task 2 print CSS forces light).
- Long resume content → overflows to page 2 silently; verify one page via print preview in Task 2.
- Order of jobs → helpers preserve array order (test in Task 1).
